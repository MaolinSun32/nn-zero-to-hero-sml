# Lecture 2: makemore — 字符级 Bigram 语言模型
#flashcards/nn-zero-to-hero


什么是 bigram？用 `emma` 举例说明（含起止标记）。
?
Bigram 是相邻两个字符组成的对（pair）。
`emma` 的 bigram（加起止符 `.`）：`.e`, `em`, `mm`, `ma`, `a.`
共 5 个 bigram，其中 `.→e` 捕捉"以 e 开头"，`a→.` 捕捉"以 a 结尾"
<!--SR:!2026-04-30,23,250-->


为什么 bigram 模型需要添加起始符和终止符？
?
- 起始符让模型学到"哪些字符容易出现在开头"
- 终止符让模型学到"哪些字符容易出现在结尾"以及"何时该停止生成"
- 没有它们，模型只能学到字符之间的转移，不知道何时开始和结束
<!--SR:!2026-06-18,52,250-->


用 `zip` 提取 bigram 的代码模式是什么？为什么这样写？
?
```python
chs = ['.'] + list(w) + ['.']
for ch1, ch2 in zip(chs, chs[1:]):
```
`zip(chs, chs[1:])` 构造滑动窗口：第一个列表和它右移一位的版本配对，自动生成所有相邻对
<!--SR:!2026-06-12,47,250-->


`dict.get(key, default)` 与 `dict[key]` 的区别？
?
- `d[key]`：找不到就抛 `KeyError`
- `d.get(key, default)`：找不到就返回 `default`（不报错）
- 常用于计数模式：`b[bigram] = b.get(bigram, 0) + 1`
<!--SR:!2026-05-01,24,250-->


bigram 计数矩阵 N 的维度为什么是 27×27？行和列分别代表什么？
?
26 个字母 + 1 个特殊符号 `.`（起止标记）= 27 种字符
- 行 = 第一个字符（前文 context）
- 列 = 第二个字符（后续 target）
- `N[i][j]` = 字符 i 后面紧跟字符 j 的次数
<!--SR:!2026-06-16,50,250-->


`stoi` 和 `itos` 分别是什么？如何构建？
?
- `stoi`：字符→索引的映射字典（string to index），`a=1, b=2, ..., z=26, '.'=0`
- `itos`：索引→字符的反向映射（index to string）
- 构建方式：先 `sorted(set(''.join(words)))` 提取所有字符，再 `enumerate` 生成映射
<!--SR:!2026-06-10,45,250-->


如何将计数矩阵 N 转换为概率矩阵 P？写出公式和代码。
?
公式：$P_{ij} = \frac{N_{ij}}{\sum_j N_{ij}}$（每行除以该行之和）
代码：
```python
P = N.float()
P = P / P.sum(1, keepdim=True)
```
每行 P_i 构成一个概率分布（和为 1），表示"在字符 i 之后各字符出现的概率"
<!--SR:!2026-04-30,23,250-->


`P.sum(1, keepdim=True)` 中的 `1` 和 `keepdim=True` 分别是什么作用？
?
- `1` 表示沿第 1 维（列方向）求和，即对每一行求和
- `keepdim=True` 保持结果维度不变（从 `(27,27)` 得到 `(27,1)` 而非 `(27,)`），以便广播除法正确执行
<!--SR:!2026-06-14,49,250-->


`torch.multinomial` 的作用是什么？在 bigram 模型中如何使用？
?
按给定的概率分布随机抽样，返回被抽中元素的索引。
在 bigram 模型中用于逐字符生成名字：
```python
ix = torch.multinomial(p, num_samples=1, replacement=True, generator=g).item()
```
`p` 是当前字符之后各字符的概率分布，采样出的 `ix` 就是下一个字符的索引
<!--SR:!2026-06-07,42,250-->


bigram 模型生成名字的完整采样循环逻辑是什么？
?
1. 从起始符 `.`（索引 0）开始
2. 查概率矩阵取当前字符对应行 `p = P[ix]`
3. 用 `torch.multinomial(p)` 按概率采样下一个字符
4. 将采样字符加入输出列表
5. 如果采到 `.`（索引 0，终止符），停止生成
6. 拼接输出列表得到生成的名字
<!--SR:!2026-04-29,22,250-->


为什么用对数似然（log-likelihood）而不直接用似然（likelihood）来评估模型？
?
似然 = 所有 bigram 概率的连乘，数值会极小（浮点下溢）。
取对数后乘法变加法：$\log \mathcal{L} = \sum \log P(y|x)$
- 数值稳定，不会下溢
- 加法比乘法计算更方便
<!--SR:!2026-06-15,49,250-->


负对数似然（NLL）作为损失函数的含义？越大还是越小越好？
?
$\text{NLL} = -\sum \log P(y|x)$
- 模型给正确答案分配的概率越高 → log 越接近 0 → NLL 越小
- 所以 NLL **越小越好**
- 完美模型在训练集上的 NLL = 0（每个正确答案概率为 1）
<!--SR:!2026-06-09,44,250-->


如果某个 bigram 在训练数据中从未出现过（如 `qg`），计算 NLL 时会出什么问题？
?
概率为 0，`log(0) = -∞`，导致 NLL 变成正无穷，损失"爆炸"
<!--SR:!2026-05-01,24,250-->


什么是拉普拉斯平滑（Add-k Smoothing）？写出公式。
?
给计数矩阵每个位置加一个常数 k，避免零概率：
$$P_{ij} = \frac{N_{ij} + k}{\sum_j (N_{ij} + k)}$$
- k=1：轻微平滑，基本保持原始分布
- k→∞：概率趋向均匀分布 1/27，完全忽略数据
<!--SR:!2026-06-11,46,250-->


什么是 one-hot 编码？为什么神经网络需要它？
?
将离散的字符索引转为固定长度的向量：只有对应位置为 1，其余为 0。
例如字符 `e`（索引 5）→ `[0,0,0,0,0,1,0,...,0]`（27 维）
神经网络需要数值输入才能做矩阵乘法，one-hot 把类别变成了数值向量
<!--SR:!2026-06-08,43,250-->


one-hot 向量乘以权重矩阵 W 实际上在做什么操作？
?
实际上是**选取 W 中对应的那一行**。
因为 one-hot 只有一个 1，矩阵乘法的结果就是 W 的第 i 行（i 是该字符的索引）。
这等价于一个查表操作（embedding lookup），但用矩阵乘法的形式可以参与梯度计算
<!--SR:!2026-04-30,23,250-->


Softmax 的计算步骤和公式是什么？
?
1. 计算 logits：`logits = xenc @ W`（线性层输出）
2. 取指数：`counts = logits.exp()`（使所有值为正）
3. 归一化：`probs = counts / counts.sum(1, keepdim=True)`
公式：$P(y|x) = \frac{e^{\text{logits}_y}}{\sum_j e^{\text{logits}_j}}$
<!--SR:!2026-06-17,51,250-->


为什么 Softmax 要先取 exp 再归一化，而不是直接对 logits 归一化？
?
- logits 可以是负数，直接归一化可能得到负概率（不合法）
- `exp()` 保证所有值为正，且保持大小关系（logit 越大 → 概率越大）
- exp 还有数学上的好处：Softmax 是对数线性模型的自然选择，使梯度计算简洁
<!--SR:!2026-06-10,45,250-->


在 bigram 这个简单场景下，神经网络方法和计数统计方法有什么关系？
?
两者在充分训练后结果**等价**：
- 统计方法直接从数据"数"出概率（查表）
- 神经网络通过学习权重 W 来逼近相同的概率分布
关键区别：神经网络框架可以推广到更复杂的模型（多层、更大 context），统计方法无法扩展
<!--SR:!2026-04-29,22,250-->


PyTorch 中 `requires_grad=True` 的作用是什么？
?
告诉 PyTorch 追踪该张量的所有运算，构建计算图。
这样在调用 `loss.backward()` 时，PyTorch 能自动计算损失对该张量的梯度（$\partial L / \partial W$）
<!--SR:!2026-06-15,50,250-->


梯度下降三步骤的代码模式是什么？
?
```python
# 1. 前向传播：计算损失
loss = -probs[torch.arange(N), ys].log().mean()
# 2. 反向传播：计算梯度
W.grad = None        # 先清零梯度！
loss.backward()
# 3. 参数更新
W.data += -lr * W.grad   # lr 是学习率
```
<!--SR:!2026-06-07,42,250-->


为什么每次反向传播前要执行 `W.grad = None`？
?
PyTorch 默认会**累加**梯度（不是覆盖）。如果不清零，新的梯度会加到旧的梯度上，导致更新方向错误。
每轮训练开始前必须清零，确保梯度只反映当前 batch 的损失
<!--SR:!2026-05-01,24,250-->


学习率（learning rate）太大或太小分别会导致什么问题？
?
- 太大：步子太大，可能越过最优点，损失来回震荡甚至发散
- 太小：步子太小，收敛极慢，需要非常多轮训练才能到达较好的解
需要选择合适的学习率使训练既稳定又高效
<!--SR:!2026-06-20,53,250-->


`probs[torch.arange(5), ys]` 这行代码在做什么？
?
高级索引（fancy indexing）：从 probs 矩阵中，取出每个样本对应正确标签位置的概率。
- `torch.arange(5)` = `[0,1,2,3,4]`（行索引）
- `ys` = 各样本的正确字符索引（列索引）
- 结果：长度为 5 的向量，每个元素是该样本的正确字符被分配到的概率
<!--SR:!2026-06-09,44,250-->


训练代码中 `+ 0.01 * (W**2).mean()` 是什么？为什么要加它？
?
L2 正则化（权重衰减）。将权重的平方均值加入损失函数。
- 惩罚过大的权重值，防止模型过拟合
- 0.01 是正则化强度，越大则越鼓励 W 接近零
- 效果：让概率分布更平滑，不会过度依赖训练数据中的偶然规律
<!--SR:!2026-04-30,23,250-->


训练好的神经网络生成名字时，和统计方法的采样循环有什么区别？
?
唯一区别在于获取概率的方式：
- 统计方法：`p = P[ix]`（查概率表）
- 神经网络：`xenc = one_hot(ix) → logits = xenc @ W → softmax → p`（前向传播）
采样逻辑完全相同：从 `.` 开始，按概率采样，遇到 `.` 停止
<!--SR:!2026-06-14,48,250-->


`torch.Generator().manual_seed(2147483647)` 的作用是什么？
?
创建一个独立的随机数生成器并设置固定种子，确保每次运行代码得到相同的随机结果（可复现性）。
不影响全局随机状态，只控制传入该 generator 的操作
<!--SR:!2026-06-06,41,250-->
