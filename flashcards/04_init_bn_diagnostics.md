# Lecture 4: Becoming a Backprop Ninja — 初始化、BN 与训练诊断
#flashcards/nn-zero-to-hero


Batch Normalization 的核心公式是什么？各项分别做什么？
?
$$\hat{x}_{ij} = \gamma_j \cdot \frac{x_{ij} - \mu_j}{\sigma_j} + \beta_j$$
减 μ（中心化）→ 除 σ（归一化到 N(0,1)）→ 乘 γ（调宽窄）→ 加 β（调位置）
<!--SR:!2026-04-03,3,250-->


BN 中的 μ 和 σ 是沿哪个维度计算的？为什么？
?
沿 **dim=0（batch 维度）** 计算：对每个神经元，在当前 mini-batch 的所有样本上求均值和标准差。
例如 hpreact 形状 (32, 200)，对每列（每个神经元）跨 32 个样本计算
<!--SR:!2026-04-03,3,250-->


BN 解决了哪三个问题？
?
1. **防止 tanh 饱和**：将输入拉回均值 0、标准差 1，落在 tanh 线性区
2. **解耦层间依赖**：消除 Internal Covariate Shift（前层变化导致后层输入分布漂移）
3. **降低对初始化的敏感度**：即使初始化不佳，BN 也会自动归一化
<!--SR:!2026-04-03,3,250-->


为什么 BN 后可以去掉偏置 b1？
?
BN 的第一步是减去均值 μ，这会把线性层的偏置直接抵消掉（b1 被减进 μ 里了），所以加了也白加
<!--SR:!2026-04-03,3,250-->


bngain (γ) 和 bnbias (β) 的作用是什么？为什么标准化后还需要它们？
?
标准化让数据回到 N(0,1) 是为了**安全起步**，但如果强制每层都是 N(0,1)，网络表达能力被限死。
γ 控制标准差（分布宽窄），β 控制均值（分布位置），让网络自己学最优分布。
初始 γ=1, β=0 → 就是 N(0,1)；训练后可能变成 N(0.3, 0.8) 等
<!--SR:!2026-04-03,3,250-->


bngain 和 bnbias 的形状为什么是 (1, n_hidden)？
?
- 第二维 = n_hidden：**每个神经元各有一对 γ 和 β**，因为最优分布不同
- 第一维 = 1：用于广播——同一个 γ 值对该神经元的所有 batch 样本一样
<!--SR:!2026-04-03,3,250-->


BN 的 mini-batch 噪声如何起到正则化作用？
?
μ 和 σ 是在随机抽取的 mini-batch（如 32 个样本）上计算的，不是全局精确值。
同一个样本在不同 batch 中得到略不同的标准化结果 → 注入噪声 → 迫使网络学习对扰动鲁棒的特征。
batch 越小噪声越大，正则化效果越强（类似 Dropout）
<!--SR:!2026-04-03,3,250-->


BN 推理时为什么不能用 mini-batch 统计量？用什么替代？
?
推理时需要**确定性**结果（同一输入每次输出相同），而 mini-batch 统计量随 batch 变化会导致预测抖动。
替代方案：用训练期间 EMA 积累的全局 running mean/std
<!--SR:!2026-04-03,3,250-->


EMA 更新全局统计量的公式是什么？momentum=0.001 意味着什么？
?
`running = 0.999 * running + 0.001 * batch_stat`
momentum=0.001 表示 running 值大约反映最近 ~1000 个 batch 的平均。
训练步数多时用小 momentum 更平滑；步数少需增大 momentum（如 PyTorch 默认 0.1）
<!--SR:!2026-04-03,3,250-->


初始 loss 的理论最优值是多少？如果远大于此说明什么？
?
理论值 = $-\log(1/27) \approx 3.296$（27 类均匀分布时的交叉熵）。
远大于此说明模型在第一步就"自信地猜错了"——W2 初始值太大 → logits 绝对值大 → softmax 极端。
修复：`W2 *= 0.01` 让初始 logits 接近 0
<!--SR:!2026-04-03,3,250-->


为什么矩阵乘法 `x @ W` 会放大标准差？放大多少倍？
?
输出的每个元素是 fan_in 个"随机数 × 随机数"的求和。
若 x ~ N(0,1), w ~ N(0,1)，每项乘积方差 = Var(x) × Var(w) = 1，求和后 Var(y) = fan_in。
所以 Std(y) = √fan_in。fan_in=30 时，输出 std 从 1 放大到 √30 ≈ 5.48
<!--SR:!2026-04-03,3,250-->


Kaiming 初始化如何修复矩阵乘法的方差放大？
?
让 $w_k \sim N(0, 1/\text{fan\_in})$，即权重除以 $\sqrt{\text{fan\_in}}$。
这样 Var(y) = fan_in × Var(x) × (1/fan_in) = 1，输出方差保持不变
<!--SR:!2026-04-03,3,250-->


tanh 对输入方差的压缩效果大约是多少？为什么？
?
tanh 将方差压缩到原来的约 **3/5**（≈ 0.6）。
因为 |x|<1 区域（68% 样本）tanh(x) ≈ x 几乎不变，但 |x|>1 区域被压向 ±1，尾部被截断 → 分布变窄
<!--SR:!2026-04-03,3,250-->


Kaiming 初始化中 gain=5/3 的作用是什么？
?
补偿 tanh 的方差压缩。tanh 把方差压到 3/5，乘以 5/3（= (3/5)⁻¹）刚好抵消。
每层线性变换输出方差略大于 1 → 经过 tanh 压缩后回到 ≈ 1 → 各层方差保持稳定。
`torch.nn.init.calculate_gain('tanh')` 返回的就是 5/3
<!--SR:!2026-04-03,3,250-->


有了 BN 之后，Kaiming 初始化和 gain=5/3 为什么不再那么重要？
?
BN 在每层强制把输入拉回 N(0,1)，所以：
- W 太大导致方差爆炸 → BN 直接除以 std 归一化
- tanh 压缩方差 → 下一层 BN 重新拉回
误差无法逐层指数累积，初始化只要"不太离谱"就行
<!--SR:!2026-04-03,3,250-->


为什么纯线性层堆叠等价于单层线性？
?
多层线性变换可合并：h₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁+b₂) = W'x + b'
无论堆多少层，结果都坍缩为一次矩阵乘法，只能表达线性关系。
tanh 打破了这个限制——非线性"折弯"使输出不能简化为线性函数
<!--SR:!2026-04-03,3,250-->


训练诊断四件套分别是什么？各自的健康信号？
?
1. **激活值分布**：各层 tanh 输出直方图形状一致，std 0.5~0.7，饱和率 <5%
2. **激活梯度分布**：各层梯度 std 在同一数量级（差距 <10 倍）
3. **权重梯度分布**：量级在 1e-3 附近
4. **update/data 比率**：log₁₀ ≈ -3（每步改变参数的 0.1%）
<!--SR:!2026-04-03,3,250-->


update/data 比率的公式是什么？log₁₀ 值太大或太小分别说明什么？
?
ratio = lr × grad.std() / data.std()
- log₁₀ ≈ -3：健康，每步微调参数的 0.1%
- log₁₀ >> -3（如 -1）：学习率太大，每步改变 10%，训练震荡
- log₁₀ << -3（如 -5）：学习率太小，每步改变 0.001%，几乎不学
<!--SR:!2026-04-03,3,250-->


`retain_grad()` 的作用是什么？为什么需要它？
?
PyTorch 默认只保留叶子节点（requires_grad=True 的参数）的梯度，中间计算结果的梯度会被丢弃以节省显存。
`layer.out.retain_grad()` 告诉 PyTorch 保留中间激活的梯度，用于可视化每层梯度流动。
仅用于诊断，生产代码不需要
<!--SR:!2026-04-03,3,250-->


激活值分布诊断中，哪些组合说明网络不健康？
?
- std < 0.1 + 饱和 ~0%：方差坍缩，增益太小，激活全挤在 0 附近
- std > 0.85 + 饱和 > 30%：严重饱和，增益太大，大量神经元卡死在 ±1
- std 逐层递减：Kaiming 增益不足，信号逐层变弱
- std 逐层递增：增益过大，信号逐层放大直到饱和
<!--SR:!2026-04-03,3,250-->


标准差 σ 可以从哪三个角度理解？
?
1. **统计视角**：每个点到均值的典型距离（均方根距离）
2. **几何视角**：数据点云的"半径"
3. **线性代数视角**：去均值向量的 L2 范数除以 √N，即 σ = ||v||₂ / √N
<!--SR:!2026-04-03,3,250-->


高斯分布的两个参数 μ 和 σ 分别控制曲线的什么？对应 BN 中的哪个参数？
?
- μ（均值）控制曲线的**左右位置**（峰值中心）→ 对应 BN 的 β（bnbias）
- σ（标准差）控制曲线的**胖瘦**（数据分散程度）→ 对应 BN 的 γ（bngain）
<!--SR:!2026-04-03,3,250-->


独立零均值随机变量乘积的方差等于什么？推导关键前提是什么？
?
$\text{Var}(x \cdot w) = \text{Var}(x) \cdot \text{Var}(w)$
关键前提：**独立** + **零均值**。
推导：E[xw] = E[x]E[w] = 0，所以 Var(xw) = E[(xw)²] = E[x²]E[w²] = Var(x)·Var(w)
<!--SR:!2026-04-03,3,250-->


标准正态分布的偶数阶矩递推公式是什么？E[x²]、E[x⁴]、E[x⁶] 分别是多少？
?
递推公式：$E[x^{2k}] = (2k-1) \cdot E[x^{2(k-1)}]$
- E[x²] = 1
- E[x⁴] = 3 × E[x²] = 3
- E[x⁶] = 5 × E[x⁴] = 15
奇数阶矩全为 0（对称分布正负抵消）。来源：分部积分降两阶
<!--SR:!2026-04-03,3,250-->


BN 中 `unbiased=False`（用 1/N 而非 1/(N-1)）的原因是什么？
?
与 PyTorch 官方 `nn.BatchNorm1d` 保持一致。
BN 的方差计算用 1/N（有偏估计），而不是统计学中常用的 1/(N-1)（无偏估计），
因为 BN 不需要做统计推断，只需要标准化当前 batch 的数据
<!--SR:!2026-04-03,3,250-->


本讲学到的概念在现代 LLM 架构中分别对应什么？
?
- BatchNorm → **RMSNorm**（省去均值中心化，更简单更快）
- Kaiming init + gain → **muP**（自动缩放，小模型超参可迁移到大模型）
- Tanh → **GeLU / SwiGLU**（更平滑，训练更稳）
- 手写训练诊断 → wandb + hook（思路一样，工具化了）
<!--SR:!2026-04-03,3,250-->


为什么 `W2` 初始化乘以 0.01（或 BN 的 `gamma *= 0.1`）？
?
让初始 logits 接近 0 → softmax 输出接近均匀分布 → 初始 loss 接近理论值 3.296。
如果 W2 太大，logits 绝对值大 → softmax 给某一类极高概率 → 猜错时 -log(p) 极大 → 初始 loss 爆炸
<!--SR:!2026-04-03,3,250-->
